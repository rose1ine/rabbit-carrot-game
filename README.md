# 토끼의 당근 피하기

위에서 떨어지는 당근을 좌우로 피하는 웹 미니게임이에요. 300점(약 15초)을 모으면 클리어예요.

- 게임 1: https://rose1ine.github.io/rabbit-carrot-game/
- 게임 2: https://rose1ine.github.io/rabbit-carrot-game/rabbit_vs_carrots.html

조작: 키보드 ←, →, 화면 아래 버튼, 게임 화면 끌기

| 파일 | 내용 |
|---|---|
| `index.html` | 게임 1 (HTML 한 파일) |
| `rabbit_vs_carrots.html` | 게임 2 (HTML 한 파일) |
| `poster.png` | 시작 화면 포스터 |
| `music.mp3` | 배경 음악 (32초 반복) |
| `ending.mp4` | 클리어 엔딩 영상 (8초) |
